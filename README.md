# Biomedical Engineering Society Project Team 2026-2027, at the University of California, San Diego.
![Project Logo](other/Hexagonal Tech Gear Badge.png)
PT Objective:
Create a glove to track a user’s hand movements using spatial motion sensing and convert data into real-time control signals for operating a prosthetic arm. Prosthetic hand relays sensory data back to the glove, providing vibrotactile feedback to the user to simulate sensation of interacting with object in prosthetic hand.
